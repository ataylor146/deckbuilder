## Inspiration
We drew inspiration from other games in the deck builder genre like *Slay the Spire* and *Balatro*, as well as drawing on OCC's pirate iconography for the theme.

## What it does
Our game gives players the chance to sail the high seas as a pirate engaging in turn based battles with rival ships using cards with special abilities

## How we built it
We built the game in the open source game engine Godot using largely handwritten code and AI assistance in bugfixes. Art was hand drawn and sound effects were drawn from free libraries.

## Challenges we ran into
We had some challenges managing the scope of the project within our limited time, but we were able to pare the game down to a set of core mechanics that were reasonable to implement within the time limit.

## Accomplishments that we're proud of
We developed a highly flexible framework for cards, abilities, and enemies which offer the ability to expand on this project greatly with more cards were it to continue development.

## What we learned
We learned about collaborative development and the object composition style promoted by Godot

## What's next for Swab The Deck
If development for this game continues then the groundwork is laid for the addition of new cards and abilities and more sophisticated enemies.
